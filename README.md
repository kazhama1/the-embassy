# 🇿🇲 Zambia High Commission (United Kingdom) – Demonstration Website

## Overview

This project is a demonstration website that showcases the functionality of a modern High Commission website. It is designed to provide information and online services for both Zambian nationals living abroad and international visitors seeking information about Zambia.

The website demonstrates how diplomatic missions can provide accessible, user-friendly, and responsive online services through a clean and modern web interface.

> **Disclaimer:** This is an educational demonstration project and is not an official website of the Zambia High Commission or the Government of the Republic of Zambia.

---

## Project Objectives

The main objectives of this project are to:

- Demonstrate the structure and functionality of a High Commission website.
- Provide an intuitive user experience for both citizens and international visitors.
- Showcase responsive web design principles.
- Present information in a clear and organized manner.
- Serve as a portfolio project demonstrating front-end web development skills.

---

## Features

- Responsive navigation menu
- Homepage with welcome section
- Latest notices and announcements
- Search functionality (demonstration)
- Contact information
- Office opening hours
- Embassy location with Google Maps integration
- Mobile-friendly responsive design
- Clean and accessible user interface
